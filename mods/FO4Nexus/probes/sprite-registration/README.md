# Sprite registration probe

This isolated data package tests shield sprite registration and mod startup only. It uses the working Nexus layout and gameplay as its parent. It does not test shield ring rendering.

The installed `FO4 Nexus` baseline remains untouched. This package is not installed automatically.

## Manual check

1. Open the Fleet Operations Mods menu.
2. Choose `Fleet Operations: Nexus UI Probe`.
3. Start a new Federation skirmish.
4. Record whether the probe loads and the match starts; this result tests registration/startup only.
