  The compatibility rebuild uses that later code; the tester's previously

Fix
- Explicit ODF *ShieldPos rectangles retain native UI placement and size.
- Only omitted/default segment rectangles scale from the128-unit canvas.
- Authored/default provenance follows the ART compass remap.
- Per-facing GUI Area overrides retain precedence; sprite selection occurs
  before default scaling as in the existing path.
- Only A2FOCraftIdentity.dll is rebuilt for this correction. Existing source
  edits outside this fix were preserved; gameplay DLLs and mod data were not
  changed. No game installation was modified by this task.
- New init diagnostic:
  Directional-shield ODF rectangles retain native UI placement; only built-in defaults scale
