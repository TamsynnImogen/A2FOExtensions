# A2FOVideo v8 automatic-skip correction

V8 is installed in the local Fleet Ops Roots installation. Manual acceptance is
pending a full restart.

## Evidence and correction

The [preserved v7 log](video-v7-skip-2026-10-03.log) shows the movie requests were
made with IntroVideo=True. MadDocSoftware and Intro each rendered nine frames
before the module reported a skip. MadDoc's AAC stream was found and waveOutOpen
returned zero. Both movies logged geometry=applied at 1920x1080 borderless.

That timing matches the 250 ms grace-period threshold in the old raw async
key-state check. A held startup/earlier-skip control is consistent with the log;
the exact control was not recorded by v7 and is not proven. The high bit reports
currently held input, not a fresh press: [Microsoft GetAsyncKeyState](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-getasynckeystate).

V8 requires all five supported skip controls to be released after the grace
period while the visible game window owns the foreground. Only a later fresh
press skips. Input in another application disarms skip. The same state is used
while rendering frames and joining the audio thread. New diagnostics record
initial/fresh masks: bits 0..4 are Escape, Space, Enter, left mouse, right mouse.

The native TBinkIntro message loop was inspected at FleetOpsHook RVA 1aa634;
its original queued-message behavior is retained. This correction is limited
to the modern dispatcher input checks; movie lookup, native fallback, display
geometry and decoding from v7 are preserved.

## Validation

Strict -Werror DLL build passed. The synthetic Win32 host tests passed for each
held control and all five together across successive movies, grace-period
presses, release/new press, low-bit-only states, foreign foreground, and idle
polling. Existing geometry and real AAC/Opus/Vorbis/short/MadDoc PCM checks also
passed. A reviewer independently checked the source and headless tests.

```bash
make video CXXFLAGS='-std=gnu++17 -O2 -Wall -Wextra -Wpedantic -Werror -DNDEBUG'
make video-test VIDEO_REFERENCE_MOVIE=build/video-fixtures/MadDocSoftware.mp4
```

These tests alter only synthetic host state. They do not automate input devices,
create windows, launch the game, or produce audible output.
